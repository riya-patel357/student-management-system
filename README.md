# Student Management System Using Python

## About the Project
This project analyzes student attendance and academic marks using Python. It calculates performance scores, classifies students, visualizes data, and groups similar students using Hierarchical Clustering.

## Technologies Used
- Python
- Pandas
- Matplotlib and Seaborn
- Scikit-learn
- SciPy
- Google Colab

## Features
- Dataset loading and cleaning
- Average marks and performance score calculation
- Student performance classification
- Data visualization using graphs
- Hierarchical Clustering with three clusters
- Dendrogram visualization

## Dataset
The dataset contains Student ID, Name, Attendance, Assignment Marks, Internal Marks, and Exam Marks.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `student_data.csv`.
3. Run all code cells.
4. View the analysis, graphs, and clustering results.
